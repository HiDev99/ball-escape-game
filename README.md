# Ball Escape Studio

A browser-based 9:16 physics video generator for creating original ball escape Shorts.

## Modes
- Escape Race
- Speed Every Bounce
- Multiply Madness
- Multi Ring Escape
- Last Trapped Wins
- Gravity Chaos
- Portal Escape
- Shrinking Arena

## Generator controls
Ball count, speed, gravity, opening size, ring rotation, ball size, neon trails, sound, titles/timer, randomizer, pause/reset, and built-in WebM recording.

## Run
Open `index.html` locally, or enable GitHub Pages for the repository (`main` branch / root).

No build system or external dependencies are required.
